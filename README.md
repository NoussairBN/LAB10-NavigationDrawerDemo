# NavigationDrawerDemo - System Dashboard

## Présentation du Projet
Ce projet est une application Android développée dans le cadre du **LAB 10**. Elle démontre l'implémentation d'un **Navigation Drawer** (menu latéral) gérant dynamiquement plusieurs **Fragments** au sein d'une seule activité.

L'application a été personnalisée avec un thème **"System Dashboard"** offrant une interface sombre moderne (#121212) avec des accents **Bleu Électrique** (#00E5FF), simulant un terminal de contrôle système.

## Concepts Techniques Abordés
- **Navigation Drawer** : Mise en place d'un tiroir de navigation standard Material Design.
- **Fragment Management** : Utilisation du `FragmentManager` pour effectuer des transactions (`replace`, `commit`) sans recharger l'activité.
- **Thématisation Avancée** : Personnalisation complète des couleurs, des styles de texte et des composants (ProgressBar, ListFragment) pour un rendu professionnel.
- **Modularité** : Séparation de l'interface utilisateur en composants réutilisables (Fragments).
- **Adaptabilité** : Gestion du bouton "Retour" physique et intégration avec la Toolbar.

## Fonctionnalités
1.  **Dashboard Overview** : Écran d'accueil présentant le statut global du système.
2.  **System Stats** : Visualisation des ressources (CPU, RAM) via des barres de progression stylisées.
3.  **Logs & Events** : Un `ListFragment` affichant les derniers événements système avec un code couleur personnalisé.
